Thorium Inbox converts PDFs you put in a dedicated folder to fixed-layout EPUB and adds them to Thorium Reader. It also imports EPUB files directly.

- Choose the watched folder during setup and change it later from the tray.
- Run in the notification area at Windows sign-in.
- Download and install Thorium Reader if setup cannot find it.
- Keep the original PDFs and find the converted copies through **Open EPUBs**.

The Windows x64 installer is signed. The accompanying SHA-256 file identifies the published download.
