Thorium Inbox converts PDFs you put in a dedicated folder to fixed-layout EPUB and adds them to Thorium Reader. It also imports EPUB files directly.

## New features

- Watch a dedicated folder and keep the original PDFs. Find converted copies through **Open EPUBs**.
- Use one desktop app for Windows, Debian/Ubuntu, and macOS. Use **Start at login** to run it in the background after sign-in.
- On Windows, choose the watched folder in setup and install Thorium Reader if setup cannot find it.
- See GitHub release notes in the app and choose **Install now** or **Later** when an update is available.

## Fixes

- Preserve the readability of ordinary PDF pages next to large foldouts.
- Confirm that Thorium Reader accepted a book before recording a successful import.

## Other changes

- Build Windows, Linux, and macOS test installers in GitHub Actions.
